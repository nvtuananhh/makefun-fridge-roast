## What it does

`main.py` (Python 3, standard library only, no network) writes one roast
of a smart fridge to `/output/entry.txt`:

> My smart fridge updated its firmware at 3 a.m., broke the ice maker, and asked me to rate the update five stars.

The line is 112 characters long. The roast lands on the judge's brief:
it is squarely aimed at the fridge itself (firmware update, ice maker),
it is a real joke with a turn rather than a mild observation, it is
specific to smart fridges, it is tight, and the twist is packed into
the last few words — the fridge that broke itself now asks for five
stars. No grocery-ordering or spying crack — the update itself is
the fresh angle.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (112 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
